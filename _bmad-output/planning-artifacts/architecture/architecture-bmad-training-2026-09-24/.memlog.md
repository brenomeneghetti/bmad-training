- (decision) [ASSUMPTION] Bind all feature units to a Functional Core / Imperative Shell paradigm with unidirectional state transitions; React components and browser adapters may invoke the core but the core never imports them, preventing competing mutation paths and browser-coupled URL semantics.
- (decision) [ASSUMPTION] One session reducer is the sole authority for Current/Last Valid URL, Draft URL, structured model, exact snapshot history, field drafts, and effect intents; every accepted mutation publishes one atomic committed state, preventing stale Copy, split views, and branchy Undo.
- (decision) [ASSUMPTION] Implement a lossless raw-token URL core: WHATWG URL is the HTTP/HTTPS acceptance and host-semantics oracle, never the round-trip serializer; custom component scanners retain exact raw tokens, empty path/query entries, separator/equal presence, percent-octet casing, and Fragment bytes, preventing browser normalization from changing untouched content.
- (decision) [ASSUMPTION] Managed non-domain fields edit component text through one codec: preserve existing valid percent triplets byte-for-byte, percent-encode newly entered structural delimiters/Unicode once with uppercase hex, reject newly introduced malformed percent triplets, and retain pre-existing malformed percent text raw until that field is corrected; unrelated changes cannot rewrite it.
- (decision) [ASSUMPTION] Use tr46 non-transitional UTS #46 conversion in both domain directions, then validate the ASCII host with WHATWG URL rules; accept standards-valid mixed-script hosts without a safety claim, always expose both bidi-isolated forms, and serialize an edited host as lowercase ASCII/Punycode while preserving an untouched accepted host lexeme.
- (decision) History snapshots own the exact committed serialization and complete lossless model; immutable non-recycled piece IDs survive edits and snapshots, and reducer-produced focus intents resolve IDs after render. This binds Undo, validation IDs, filtering, and focus so reparsing cannot silently replace identity.
- (decision) [ASSUMPTION] Render the complete managed-piece list in V1 and prohibit virtualization; 250+ rows do not justify an inaccessible second representation. Revisit only if release fixtures miss interaction targets and an accessibility-equivalent prototype passes the mandated matrix.
- (decision) [ASSUMPTION] Parse synchronously inside the pure core and publish through one reducer transition; keep generation IDs only for deferred/scheduled Full URL parsing. Do not add a worker unless reference-hardware profiling exceeds 50 ms p95, at which point a worker adapter must preserve the same core contract and discard stale generations.
- (decision) All URL-bearing failures are typed local values with stable non-content codes; components render safe messages and no URL content reaches console logs, analytics, crash reporting, storage, query strings, or outbound requests.
