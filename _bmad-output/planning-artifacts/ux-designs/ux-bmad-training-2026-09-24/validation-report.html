Five original accessibility findings. A11Y-01 — Search-hidden error recovery

EXPERIENCE Feedback channels
A summary link can target an excluded field.
Fix: disclose Search clearing in the action label; clear only when needed with count feedback, expand/focus stable field preserving rejected text/error; otherwise preserve Search. Addressed.

A11Y-03 — Stale drag-preview speech

EXPERIENCE Feedback channels / Drag transaction
Queued transient destinations can outlive the gesture.
Fix: latest-destination coalescing at bounded cadence, transaction/source-revision binding and invalidation before final outcome; visible destination retained. Addressed.

A11Y-04 — Dense-list keyboard return

Both navigation-link rows; EXPERIENCE Utility navigation

Fix: bottom and focus-revealed row return links to Full URL/Copy and Search; explicit unobscured focus with preserved state and no editing-key interception. Addressed.
